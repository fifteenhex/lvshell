# Built-in music

Module files placed here are installed to `/usr/share/lvshell/music` and
played as the default background music when the user has not added their own
under `/data/music`. Any format libxmp understands works (`.mod`, `.xm`,
`.s3m`, `.it`, ...).

`4mat-nintendochiptune.mod` is the Protracker chiptune "nintendochiptune" by
4-Mat (Matt Simmonds), from the freely-distributed Amiga module collection
(modland / exotica). Shipped uncompressed so no LHA decompressor is needed at
build time.
